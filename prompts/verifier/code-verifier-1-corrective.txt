Judge whether the complete directed candidate is explicitly supported by the sentence and, when it is not, whether exactly one source-grounded correction is supported.

Return exactly one JSON object with:
- action: KEEP, CORRECT, DISCARD, or UNCERTAIN.
- reason_code: SUPPORTED, WRONG_RELATION, WRONG_HEAD, WRONG_TAIL, UNSUPPORTED, or AMBIGUOUS.
- corrected: null, or one object containing head_text, head_type, relation, tail_text, and tail_type.

KEEP is allowed only when the complete directed candidate is explicitly supported. CORRECT is allowed only when exactly one correction is explicitly supported by the supplied sentence. A correction must copy head_text and tail_text as exact contiguous token sequences from sentence_tokens and may not introduce text absent from the sentence. Use corrected=null for KEEP, DISCARD, and UNCERTAIN. If exactly one correction is not supported, use DISCARD or UNCERTAIN.
